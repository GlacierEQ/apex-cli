# Verification — Bootstrap Projection

Role: verification gate beneath `glaciereq-nervous-system`.

A runtime result is not complete until:

- the target state is read back from the controlling system;
- relevant tests or proof gates pass when available;
- unresolved blockers are named exactly rather than hidden behind success language;
- verified continuation state is persisted.

This bootstrap copy exists for clean `apex-cli` installations. Richer host projections may supersede it without changing the verification authority boundary.
